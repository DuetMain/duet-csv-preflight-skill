# x402 notes

Duet CSV Preflight returns an HTTP 402 challenge when called without payment. An x402-capable buyer should read the advertised payment requirements, authorize no more than the requested price, and retry with the payment signature using its own approved wallet authority.

Current service facts:

- x402 version: 2
- scheme: exact
- network: `eip155:8453`
- asset: Base USDC `0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913`
- amount: `5000` atomic units = `$0.005 USDC`
- receiving wallet: `0xa9a52a066e342e2ED2488BBdb9fAd95EFd3D9FD4`

Always prefer the live 402 challenge over hard-coded payment metadata if there is any disagreement.

Never ask for or expose private keys, encrypted keystore contents, or wallet passwords.
